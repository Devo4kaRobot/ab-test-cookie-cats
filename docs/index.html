Расчёт по нормальному приближению для разности двух долей, двусторонний тест. Дисперсия берётся по альтернативе: p₁(1−p₁) + p₂(1−p₂). CUPED уменьшает дисперсию в (1 − ρ²) раз, поэтому и нужная выборка уменьшается во столько же. Длительность округлена до целых дней; на практике тест стоит гонять полными неделями, чтобы не поймать эффект дня недели. Код и разбор теста: github.com/Devo4kaRobot/ab-test-cookie-cats.
